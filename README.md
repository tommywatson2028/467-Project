# 467-Project
Team name: NEMT Auto
Team members: Megumi Goto, Niko Kertscher-Flores, Ewan Freestrom, Tommy Watson
Assigned project: Auto parts product system
Brief project description: Full-stack e-commerce system for an auto parts catalog business. With online ordering, credit card authorization, inventory management, and warehouse packing/shipping workflows, an admin interface for order tracking and shipping rate configuration.
Initial project goals: A Store, Checkout Page, Auto part legacy database, Credit Card verification, Packing list database, employee page for receiving parts, and a separate data base for employees to set weight brackets and view orders, based on factors such as date range, status, or price, also send an email to the user.
